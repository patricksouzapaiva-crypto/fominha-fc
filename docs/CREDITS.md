# Créditos de som

As amostras ficam em `assets/snd/`, em mono, 22050 Hz, Ogg Vorbis. O jogo baixa cada arquivo quando o som é ligado. Se o download falhar, volta ao som gerado no navegador.

| Arquivo | Uso | Origem | Licença |
| --- | --- | --- | --- |
| `crowd.ogg` | murmulho da arquibancada, em loop | Gregor Quendel, “10 Ambience”, pacote [Free Crowd Cheering Sounds](https://opengameart.org/content/free-crowd-cheering-sounds) | CC BY 4.0. Crédito: Gregor Quendel, [gregorquendel.com](https://www.gregorquendel.com) |
| `roar.ogg` | explosão no gol | Gregor Quendel, “04 Strong cheering II Short”, mesmo pacote | CC BY 4.0 |
| `chant.ogg` | canto em lance de pressão | Gregor Quendel, “08 Rhythmic cheering”, mesmo pacote | CC BY 4.0 |
| `groan.ogg` | “uuuh” em chute pra fora ou na trave | Gregor Quendel, “06 Soft cheering II”, mesmo pacote | CC BY 4.0 |
| `boo.ogg` | vaia quando o rival marca | StarNinjas, [Crowd Shouting/Speaking Ambience](https://opengameart.org/content/crowd-shoutingspeaking-ambience), trecho a partir de 1s | CC0 |
| `whistle.ogg` | apito curto | SFXMint, [instrument whistle 09](https://sfxmint.com/sounds/instrument-whistle) (`instrument-whistle-09.mp3`) | CC0 |
| `whistle-long.ogg` | apito de fim de jogo | SFXMint, [instrument whistle 12](https://sfxmint.com/sounds/instrument-whistle) (`instrument-whistle-12.mp3`) | CC0 |
| `kick.ogg` | chute | Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds), `impactSoft_medium_001.ogg` | CC0 |
| `net.ogg` | bola na rede | Kenney, Impact Sounds, `impactSoft_heavy_000.ogg` | CC0 |
| `post.ogg` | bola na trave | Kenney, Impact Sounds, `impactMetal_light_001.ogg` | CC0 |
| `click.ogg` | toque de interface | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds), `click_001.ogg` | CC0 |
| `card.ogg` | carta jogada | Kenney, Interface Sounds, `select_003.ogg` | CC0 |
| `fanfare.ogg` | título e mentor | Kenney, Interface Sounds, `confirmation_001.ogg` | CC0 |

Os impactos e os sons de interface da Kenney foram gerados no GameSynth (Tsugi) e publicados por ele em CC0. Não são gravação de campo de uma bola. A vaia é um coro de vozes em CC0, não uma arquibancada de estádio. O apito é de instrumento, publicado como apito de árbitro pela SFXMint.

Ilustrações dos lances épicos: arte original gerada para o projeto Fominha FC. Os arquivos ficam em `assets/epic/` e só são pedidos quando um lance épico vai aparecer ou quando a tela de resultado monta o card. Se a imagem não carregar, o replay volta para o desenho em SVG.
